# Changelog

All notable changes are documented here. This project follows semantic versioning for the package and separately versions the portable contract.

## [0.1.0] - 2026-08-04

### Added

- Generator Contract 1.0 and its JSON Schema.
- Provider-neutral runner registry and validated execution pipeline.
- Text, number, boolean, select, array, object, and nested output contracts.
- Deterministic seeded random helper.
- Name, Unicode, and structured-brief reference generators.
- Security limits, typed errors, tests, CI, and contributor documentation.
